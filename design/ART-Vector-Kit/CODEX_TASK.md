# Задача для Codex: ART — музейные SVG, уровни K-001/K-002 и палитры рядом с произведениями

Работаешь в **текущей локальной версии ART**, не переписывай и не заменяй проект старыми исходниками. В корне проекта в `design/ART-Vector-Kit/` лежит архив SVG (либо его распакованное содержимое). Сначала прочти `README.md`, `manifest.json`, просмотри `preview/reference-approved.png`, `preview/vector-atlas.png` и `preview/index.html`. Новый комплект — набор реальных, редактируемых SVG-контуров, не PNG внутри SVG.

**Цель:** внедрить утверждённую авангардную минималистичную графику в две *независимые* ветки секретного музея; во всех местах показа произведений добавить мини-палитру для сохранения характерных цветов; в «Моих уроках» дать доступ к палитрам связанных произведений; заменить стандартные стрелки контекстного перехода на рисованную трёхштриховую стрелку.

## А. Использование SVG и общий color provider

1. Перенеси runtime SVG в папку ассетов, которую действительно копирует `scripts/build.mjs` в `dist`. Не копируй в публикацию `preview/reference-approved.png`, markdown-инструкции и редакторские файлы.
2. Все SVG используют `--art-c1`, `--art-c2`, `--art-c3`. **Не подключай переменно окрашиваемый SVG только через `<img src>`**: CSS custom properties родителя туда не попадут. Используй доверенный inline SVG компонент / встраивание статического SVG как текста на этапе сборки. Исключи внедрение пользовательского HTML или чужих SVG. Сохрани `viewBox`, семантику, размеры и `stroke-linecap`.
3. Цветовая схема берётся из **существующего источника правды** (color provider). Активные цвета — последние **3 уникально сохранённые записи** в хронологическом порядке `savedAt` (уточни фактическую модель и правила уникальности). Не дублируй стор и не вводи `Math.random()` в render. При 0 цветах все токены нейтрально-серые; при 1 или 2 цветах недостающие слоты серые. Смена активных цветов происходит сразу после добавления/удаления цвета без перезагрузки приложения.
4. Свотчи произведения всегда берутся из `artwork.palette` (2–5 проверенных HEX), **не** из последних пользовательских цветов.
5. Не меняй фирменную белую иконку ART и типографику. Фоны и основной текст остаются нейтральными. Тёмные контуры портретов не должны терять читаемость.

## Б. K-001 — 5 уровней развития мужичка

**Не ломать уже установленную пасхалку K-001**: она открывается после 7 уникальных сохранённых произведений, затем остаётся доступной; состояние хранится локально и присутствует в JSON-экспорте.

Использовать `svg/k001/levels/level-N.svg`:

- 7–11 картин — L1, неатрибутированный мужичок;
- 12–19 — L2, культурно значимый;
- 20–34 — L3, музейного значения;
- 35–59 — L4, особо ценный;
- 60+ — L5, национальное достояние.

Дополнительно учитывать преобладающую художественную эпоху / школу в галерее. При равенстве — последняя сохранённая работа (если такое правило уже есть, сохранить). Сопоставить периоды с одним из восьми ключей (`archaic`, `sacred`, `humanist`, `dramatic`, `natural-light`, `nervous`, `constructive`, `reality-disputed`). Не делать бессмысленную классификацию незнакомой эпохи: предусмотреть нейтральный fallback.

Рисовать уровневый портрет с `svg/k001/overlays/<school>.svg` **под ним**. Обе SVG имеют совпадающий viewBox. В `svg/k001/schools` есть 8 полных самостоятельных портретов как визуальный эталон; не клади эти портреты поверх базового изображения, иначе получится два лица. Статусы `svg/k001/status` показывай рядом с музейным досье, а не поверх головы.

Статусы по уровням: `not-for-catalog`, `conditionally-admitted`, `internal-fund`, `special-storage`, `permanent-exhibition`.

Зависимость K-001 от *любимых работ*, художественных школ и общей пользовательской палитры сохраняется; **создание AI-уроков не должно повышать K-001**.

## В. K-002 — независимая «К-002 / Мужичок-создатель»

Добавить в «Автопортрет» отдельный секретный музейный экспонат, который тихо появляется **после трёх успешно созданных и сохранённых персональных AI-уроков**. Он развивается независимо от K-001:

- 0–2 — не виден;
- 3–6 — `svg/k002/levels/level-1.svg`, «Причастный к созданию»;
- 7–14 — L2, «Кустарное производство»;
- 15–29 — L3, «Деятель просвещения»;
- 30–59 — L4, «Промышленного масштаба»;
- 60+ — L5, «Министерство культуры».

Считать **один раз на уникальный ID фактически успешно созданного и сохранённого пользователем AI-урока**. Не считать официальные уроки, предпросмотры, тренировки, повторное сохранение/просмотр, неуспешные генерации, дубликаты при импорте. Удаление созданного урока не понижает уже достигнутый уровень K-002. Сохранить историю созданных ID в IndexedDB и JSON экспорте/импорте, объединив уникальные ID при импорте.

Уровень/раскрытие/статусы и статистика K-002 не должны зависеть от художественной школы или количества картин K-001. Общие только три последних пользовательских цвета **для графики**, не для подсчёта.

В отдельном музейном досье по нажатию на плашку: SVG-эмблема соответствующего уровня, название, строгий абсурдно-официальный текст заключения, текущий счётчик, следующая граница. Никаких конфетти, уведомлений или обязательного popup. Escape, overlay-dismiss, focus trap, restore focus, iOS safe-area. Постоянные пользовательские данные не очищать при обновлении PWA.

## Г. Мини-палитра сбоку у всех произведений

Создать универсальный переиспользуемый компонент `ArtworkQuickPalette` (или в соответствии с текущей архитектурой), использующий `svg/ui/artist-palette.svg`.

Поведение:

1. На **каждом значимом изображении произведения** с проверенной `artwork.palette` показывать небольшую иконку палитры у боковой границы изображения (максимально деликатно, не заслоняя искусство). Включая: карточку произведения, полный экран, официальные и AI-уроки, сравнения, блоки «Твоё наблюдение», экран тренировки, галерею, просмотр сохранённых уроков. Если нет достоверного `artworkId` / палитры — кнопку не показывать. Не выводить несколько одинаковых триггеров поверх одного изображения.
2. На нажатие — компактный popover, а на узком экране, если необходимо, bottom sheet; показывать **2–5 оригинальных цветов этой конкретной картины**, с доступным названием/HEX и состоянием сохранения. При клике по свотчу — использовать СУЩЕСТВУЮЩУЮ логику добавления цвета в личную коллекцию, сохраняя `artworkId`, HEX, `savedAt`. Не создавать отдельное хранилище или параллельный API сохранения цветов.
3. Для уже сохранённого цвета показывать `✓` и исключать повторную вставку той же записи по принятой модели уникальности; если одинаковый HEX у разных произведений, не терять привязку к источнику, следовать текущим правилам. Возможность сохранить несколько цветов подряд без закрытия панели.
4. Изменения тут же отражаются в «Моих цветах», последних трёх цветах, раскраске интерфейсных иконок и обоих секретных экспонатах. Не менять текущую основную полноценную палитру в карточке произведения, это **дополнительная точка входа**.
5. Особенно в тестах: по иконке можно нажимать, **не отправляя ответ** на вопрос. Не перекрывать кнопки выбора, просмотр деталей, pinch-zoom / открытие изображения. Активная иконка не должна закрывать важные фрагменты картины. При необходимости применять side-gutter вне картинки на мобильном и небольшой inset на широких экранах.
6. Pointer and keyboard: реальный `<button>`, `aria-label="Палитра произведения: <название>"`, фокус и закрытие по Escape, по повторному нажатию, по клику вне панели, возврат фокуса в trigger. Минимальная область касания около 44px, визуальная пиктограмма может быть меньше. Правильно на iOS Safari.

## Д. Палитры в «Моих уроках» и в сохранённых уроках

Показывать палитры связанных произведений не только на экране конкретного произведения, но и в «Моих уроках». Не загромождать список: на карточке — компактная палитра основной картины + переход к полному списку; на экране урока — быстрые палитры всех работ, к которым урок привязан. Каждый цвет можно сохранить тем же единым действием, с сохранением `artworkId` и состоянием уже сохранённого оттенка. Не подставлять цвета из другого произведения или сгенерированные Gemini цвета. Если связан только урок без валидных artworkId — не показывать искусственную палитру.

## Е. Художественные стрелки и мини-рамка

`svg/ui/three-stroke-arrow.svg` — использовать вместо стандартной стрелки **в контекстных действиях** (`Открыть`, `Продолжить`, `Завершить`, переход в урок, следующий вопрос), а не вместо системной кнопки «Назад», крестика модалки или навигации табов.

Три отдельные линии стрелки берут по одному цветовому слоту `--art-c1..3`. Стрелка без сохранённых цветов — монохромная. Её SVG не должен превращаться в чёрное пятно на iOS.

`svg/ui/mini-frame.svg` — для отдельных действий в «Моей галерее» или открытия сохранённого произведения; не делай его универсальным заменителем всех стрелок.

## Ж. Техническая приёмка

- Изучи текущие файлы и интегрируй по месту: Vue 3, нынешний color provider, IndexedDB, JSON-архив, Netlify/Gemini, PWA.
- Перенеси только нужные SVG в `dist` в production build. Для динамики используйте inline SVG с CSS vars, в том числе при переходах через `Vue` и iOS Safari. Не ставь `v-html` с данными пользователя или внешнего API.
- Проверить цвета: 0/1/2/3/4 сохранения, удаление последнего, перезапуск, повторное сохранение того же цвета, смена художественной школы и уровня, отсутствие сдвигов layout.
- Проверить K-001 границы 6/7/11/12/19/20/34/35/59/60, K-002 границы 2/3/6/7/14/15/29/30/59/60, два независимых счётчика, устойчивость к импорту и удалению уроков.
- Проверить палитру возле картины в уроках, практике и галерее, правильность source `artworkId`, отсутствие перехвата ответа в квизе, доступность и iPhone safe-area.
- Добавить unit/interaction tests, `npm test`, `node scripts/build.mjs`, Chromium responsive checks. Для Safari/WebKit отдельно обозначить, что проверялось реально, а что нет.
- Обновить PWA service-worker cache version и обеспечить получение SVG новой версии без удаления пользовательских данных.
- Финальный отчёт: изменённые файлы, реализованные экраны, тесты, список невыполненного и точные шаги публикации через `npx netlify-cli@latest deploy --prod`.

**Ограничение:** не изменяй алгоритмы Gemini, его секреты, художественные факты и данные каталога за пределами необходимых привязок палитр; не меняй белую иконку ART. Не утверждай, что иллюстрации автоматически точно повторяют референс до пикселя: это векторная перерисовка, при необходимости можно скорректировать пути.
