# ART · K-001 + K-002 · SVG vector kit

Векторный набор для интеграции в **актуальную** рабочую версию ART (не заменяет существующий проект).

## Важное уточнение о визуальной точности

SVG **перерисованы вручную по утверждённому изображению** `preview/reference-approved.png`. Это настоящие редактируемые пути, а не PNG, встроенный в SVG. Стиль, композиции, три пользователя цвета, тонкие линии и авангардные формы максимально приближены к утверждённому референсу. Однако **попиксельное совпадение с растровым референсом не заявляется**. Перед продакшеном можно подправить отдельные path по наложению на оригинал.

## Содержимое

- `svg/k001/levels/` — 5 рисунков мужичка по уровню коллекции.
- `svg/k001/schools/` — 8 самостоятельных иллюстраций художественных школ (для визуального эталона типологии).
- `svg/k001/overlays/` — 8 прозрачных фоновых модификаторов в едином `viewBox=0 0 240 240`; **эти** слои можно комбинировать с 5 портретами разных уровней.
- `svg/k001/status/` — 5 музейных статусных знаков.
- `svg/k002/levels/` — 5 независимых эмблем мужичка-создателя.
- `svg/ui/artist-palette.svg` — микро-палитра художника, управляющая быстрым сохранением цветов произведения.
- `svg/ui/mini-frame.svg` — рамка для избранного/галереи.
- `svg/ui/three-stroke-arrow.svg` — художественная стрелка из трёх раздельных штрихов.
- `manifest.json` — пороги и идентификаторы.
- `preview/index.html` — самодостаточный интерактивный стенд для проверки пользовательских цветов.
- `preview/vector-atlas.png` — предпросмотр готовых векторов.
- `preview/reference-approved.png` — утверждённое визуальное направление (референс, **не** runtime-asset).
- `CODEX_TASK.md` — полное техническое задание для интеграции.

Всего **34 SVG**. Никаких растровых зависимостей для самих иконок и портретов.

## Цветовой контракт

Все SVG используют три CSS custom properties:

```css
.art-vector {
  --art-c1: #86A09A;
  --art-c2: #D7A49C;
  --art-c3: #9DAFBE;
}
```

Это **пример** цветного состояния, не постоянная тема. До появления пользовательских сохранённых оттенков задавайте нейтральные значения (`#898989`, `#ADADAD`, `#777777`). После сохранения выбирайте только 3 последние уникальные записи цветов по реальному времени сохранения. При нехватке цветов — оставшиеся цветовые слоты серые. Фоновый интерфейс не перекрашиваем.

**Важно:** для CSS-переменных нужен **inline `<svg>`**, так как `<img src="...svg">` не наследует CSS-переменные родителя. Простой способ: загрузить известные статические файлы в рамках сборки и сгенерировать trusted Vue-рендереры или импортировать текст локального SVG; никогда не рендерить произвольный пользовательский SVG как HTML.

## Композиция K-001

Слои идут в таком порядке:

1. `svg/k001/overlays/<school>.svg` — фоновые формы по доминирующей художественной школе.
2. `svg/k001/levels/level-N.svg` — портрет нужной стадии.
3. `svg/k001/status/<status>.svg` — **не поверх лица**; статусный знак рядом с карточкой или в музейной рамке.

`schools/*.svg` — отдельные стилистические портреты для согласования визуального языка, **не предназначены для наложения целиком** поверх уровневого портрета.

Для сборки первых двух слоёв извлеките trusted SVG-child nodes из известных локальных файлов (общий viewBox) или оформите их как Vue SVG-компоненты. Можно упростить это до выбора портрета и отдельного фонового модификатора.

## Локальная демонстрация

```bash
cd ART-Vector-Kit
python3 -m http.server 8080
```

Открой `http://localhost:8080/preview/` и меняй три цвета. Это **галерея векторов**, не текущая PWA.
